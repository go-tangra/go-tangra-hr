# hr join bundle

Generated by the gateway (Gateway operations › Modules › hr › Add).

    cp /path/to/core-valkey-ca.pem private/valkey-ca.pem
    docker compose up -d

hr needs the core's platform event bus: the Valkey address you gave must be
reachable from this host over TLS, with a Valkey user `hr`, and
`private/valkey-ca.pem` must be the CA of its certificate. The notification,
signing and scheduler addresses must be reachable over the mesh as well, and
the core's scheduler needs `discovery.static.hr: ["<this host>:9925"]` to
run hr's tasks.

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the Valkey password. Keep
both on this host only. The enrolment token is valid for the lifetime chosen
in the wizard; after the first start the module renews its identity itself.
